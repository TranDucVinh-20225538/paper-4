## Reading this matrix

No cell in this table is evidence *for* the hypothesis — every row is a way the hypothesis (or a
competitor) could be shown wrong, plus the counter-argument a defender could raise if the
falsifying observation actually occurred. The lowest-confidence row is P3 (architecture
independence), which is also the row closest to this project's original motivating question — a
useful, humbling reminder that the most interesting claim is also the hardest one to actually
nail down with a two-architecture comparison. The Alt-1-vs-KDE tension (row 4) is the one place
this session's own prior work (Paper 3) already provides a partial, if inconclusive, distinguishing
data point without any new experiment.

This matrix does not select or reject anything. It exists to be consulted when Step 6 designs
are drafted, so that each design choice can be checked against what it would need to survive.
