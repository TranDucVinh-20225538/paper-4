# Running this analysis on your own machine

Every table in the manuscript is regenerated by a script in `PhaseB/analysis/`.
Most of them need nothing but this repository and one bundle of extracted
arrays. This file says which, and what the rest additionally need.

## 1. Clone and check

    git clone -b public git@github.com:TranDucVinh-20225538/paper-4.git
    cd paper-4
    python3 PhaseB/analysis/data_roots.py

The check prints where each external data root resolves. Out of the box they
point at the layout the study was run on, so on your machine most will read
MISSING. That is expected and mostly harmless: the table-producing analysis does
not read any of them.

## 2. Unpack the arrays

The embeddings and per-example scores are extracted output, not source, so
`.gitignore` excludes them for the same reason it excludes the 1.35 GB backbone.
Both bundles are release assets:

    unzip embeddings_items1_4.zip      # 129 MB: reference embeddings, the
                                       #   reference artifact, the nuisance
                                       #   direction, and the external .npz
    unzip per_example_scores.zip       # 40 MB: per-example scores, 10-seed outputs

Check them against the hashes the repository already carries:

    shasum -c PhaseB/assets/reference_embeddings/ReferenceEmbedding/sha256.txt
    shasum -c PhaseB/outputs/phase3/sha256.txt

## 3. Run

These reproduce the manuscript's tables from the two bundles alone:

| Script | Produces |
|---|---|
| `rq3_augmented_matching.py` | Table 8, Table 10 |
| `rq3_geometry_matching.py` | the registered matched contrast |
| `phase3_external_rq3.py` | Phase 3, the twelve external combinations |
| `exploratory_reporting.py` | the permutation families |
| `lid_spectral_decay.py` | the spectral analysis |
| `rq3_residual_model.py` | the mixed-effects family |
| `utility_noninferiority.py` | the utility margin |
| `geometry_dose_response.py` | the dose-response record |
| `verify_manuscript_numbers.py` | checks RQ2 figures against the artifacts |

`rq1_susceptibility.py`, `verify_scorer_invariance.py` and
`phase3_external_rq1.py` also run, the first two from the second bundle and the
third from the first.

## 4. What needs more than the bundles

Four scripts import `src` from the Paper 1/2 repository, which carries the
scorer implementations this study reuses unmodified:

    git clone git@github.com:TranDucVinh-20225538/CSG-SKin.git
    export PAPER4_CSG_ROOT=$PWD/CSG-SKin

That covers `hierarchical_auroc_ci.py`, `rq1_numerical_bounds.py`,
`fine_gamma_score.py` and `generate_per_example_scores.py`. The last of these
also wants the trained adapters, 290 MB, which are not distributed because the
scores it would produce are already in the second bundle.

`verify_dissociation_ratio.py` and `build_unified_matrix.py` read Paper 3's
checkpoint matrix; set `PAPER4_PAPER3` if you have that repository.

## 5. What cannot be re-run

Stage 3.0's artifact audit and the duplicate registry open the source images.
Those corpora were deleted from the machine this study ran on, and the
hash-pinned embedding artifacts are what survives of them. Re-running those two
stages means obtaining ISIC 2019, PAD-UFES-20, Derm7pt and PH2 from their
distributors, downloading the PanDerm checkpoint, and setting `PAPER4_ARCHIVE`,
`PAPER4_CSG_ROOT`, `PAPER4_DERM7PT` and `PAPER4_PH2`. Everything downstream of
the embeddings runs without them.
