# Execution Amendment EA-01

**This is an Execution Amendment, not a protocol deviation.** Distinct category, per Vinh
(2026-08-05): an Execution Amendment corrects the *execution specification* (what a stage was
scoped to actually do) when it turns out incomplete relative to the protocol's own requirements. A
protocol deviation (`24_PreRegistration.md` §13) changes the *preregistered design itself*
(hypothesis, prediction, claim, outcome criterion). EA-01 is the former — nothing preregistered is
being touched.

## Why this doesn't reopen the protocol

`22_Experimental_Design.md` §2 already names a train split as in-scope for "the FM arm" generally.
Stage 2.1's actual extraction scope resolved an unstated case (does the *Reference* arm specifically
need it) one way — held-out only — and that resolution is what's being corrected here, not the
protocol text itself. See `ReferenceArmBaseline/GroupB_protocol_reconciliation.md` §4 for the full
reasoning.

## What approval authorizes

A new extraction (Stage 2.1-equivalent scope, applied to the ISIC train split instead of the
held-out evaluation split) producing `ReferenceTrainEmbedding/`, frozen and provenance-tracked the
same way as `ReferenceEmbedding/` (Embedding Integrity Gate, manifest, SHA256, immutability). Once
it exists (lifecycle → Implemented), Group B's training-population-dependent scorers (Mahalanobis,
kNN, cosine-to-centroid, KDE) can be computed. Energy and ViM additionally require a trained
classifier head, which this amendment does not address — a separate decision, still open.

**Executed 2026-08-05.** Gate PASS (5/5: shape, sample count, ordering, label alignment, SHA256),
frozen chmod 444/555. Manifest scope-locked with `population`/`purpose`/`not_for` fields so the two
artifacts cannot be conflated:

| Artifact | Population | Used for |
|---|---|---|
| `ReferenceEmbedding` | Held-out ID (ISIC-test, n=5,067) + OOD (PAD-UFES, n=2,298) | Evaluation |
| `ReferenceTrainEmbedding` | ISIC 2019 train (n=16,211) | Reference fitting (Group B scorers only) |

**No Group B scorer has been computed.** This remains infrastructure-building, not scientific
analysis, per Vinh's explicit instruction (2026-08-05): do not run Mahalanobis, kNN, KDE, Energy, or
ViM until the artifact has been reviewed.

## What this amendment does not authorize

Approval of EA-01 authorizes exactly one thing: extracting `ReferenceTrainEmbedding/` as specified
above. It does **not** authorize running any Group B scorer, computing per-direction variance, or
any change to `ReferenceEmbedding/`, `BaselineReport/`, or any preregistered document. Those remain
separate, explicit PI decisions once `ReferenceTrainEmbedding/` exists and passes its own Embedding
Integrity Gate.
