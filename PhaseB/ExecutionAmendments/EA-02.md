# Execution Amendment EA-02

**Execution Amendment, not a Protocol Deviation.** `22_Experimental_Design.md` §3.5 states Gate 1's
intent correctly and completely ("did LID and/or spectral-decay slope actually change") but leaves
the operational PASS criterion unspecified — no threshold, no test. This amendment fills that gap;
it does not change what Gate 1 is for.

| Field | Value |
|---|---|
| **Reason** | Gate 1 has no numeric PASS/FAIL criterion anywhere in the locked protocol; the width-selection loop (Execution Plan v2 Step 3) produced real LID/slope measurements with no rule to convert them to PASS/FAIL |
| **Affected stage** | Stage 4, all Gate 1 checks (width selection, λ_proj selection, per-α checks, both Intervention and Conventional arms) |
| **Protocol impact** | None — Gate 1 remains a manipulation check, not a hypothesis test, exactly as `22_Experimental_Design.md` §3.5 already states |
| **Claim impact** | None |
| **Hypothesis impact** | None |
| **Constitution impact** | None |
| **Status** | **Approved** (2026-08-05), full wording given by Vinh directly, applied immediately |

## Criterion

```
Gate 1 (Manipulation Check)
PASS iff the intervention produces a reproducible monotonic change in at least one
preregistered geometry metric (LID or spectral-decay slope) relative to the reference artifact.

Gate 1 is a manipulation check only. It is not evidence supporting or contradicting the hypothesis.
```

No arbitrary percentage, no p-value, no effect size — deliberately, per Vinh: those are Stage 5's
job once seeds are pooled, not this gate's. At single-seed, single-checkpoint granularity (width and
λ_proj selection), "reproducible" reduces to: the computed value differs from baseline as an actual
distinct measurement, not by a fluke of an unchanged pipeline.

**Applied interpretation, width-selection stage specifically (flagged, not silently assumed)**: "the
intervention ladder" most precisely names the α-dose ladder (`0, .25, .5, .75, 1`, Method
Specification §3) — the one axis with a real, preregistered ordering. The width grid (`r`) is a
capacity probe, not itself a dose axis, so monotonicity is not required *across r*; what's checked
here is a measurable, correctly-directed change from baseline *at* each `r`. Monotonicity *across
α* is checked properly once the α-ladder itself runs (Step 6).
