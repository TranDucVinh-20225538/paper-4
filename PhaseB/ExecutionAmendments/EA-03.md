**Execution Amendment, not a Protocol Deviation, not a re-run.** EA-02's operational wording
("monotonic") over-constrained Gate 1 beyond what `22_Experimental_Design.md` §3.5 actually asks
for — the α-ladder's own real output exposed this, not a design review. The manipulation check's
purpose (did the intervention actually move geometry) is unchanged; only the word describing what
counts as "moved" is corrected.

## Revised criterion (replaces EA-02's wording)

```
Gate 1 (Manipulation Check)

PASS iff a preregistered geometry metric (LID or spectral-decay slope) exhibits a
reproducible dependence on intervention dose.

No assumption is made about linearity, strict monotonicity, or convexity.
The shape of the response is empirical, not prespecified.

Gate 1 is satisfied if at least one preregistered geometry metric shows reproducible dose
dependence. The remaining geometry metrics are recorded individually and are not ignored.

Gate 1 is a manipulation check only. It is not evidence supporting or contradicting the hypothesis.
```

**Wording correction (2026-08-05, per Vinh)**: "at least one ... PASSES" alone reads as license to
discard whichever metric doesn't cooperate. The criterion is satisfied by one metric reproducing;
every metric is still reported, not selected among.

## Operationalization applied to the existing α-ladder data (no new data generated)

"Reproducible" keeps the same meaning EA-02 already used elsewhere in this project (every seed
individually agreeing, not just the mean): for a given `α > 0`, Gate 1 is **satisfied** if at least
one geometry metric deviates from the `α=0` baseline in the **same direction across all 5 seeds** —
no requirement on the shape of that deviation as `α` continues to increase. Both LID and slope are
recorded at every `α`, pass or not, in every output this criterion is applied to.

## Explicitly not done

No re-run, no new training, no new embeddings. No interpretation of the drop-then-recover slope
pattern — it is recorded as an observed response shape, nothing more, pending Stage 5. The existing
`AlphaLadder/alpha_ladder_results.json` is re-scored under this revised criterion in
`26_Lab_Notebook.md`, not regenerated.

## Gate 1 is now locked (2026-08-05, per Vinh, standing rule for the rest of Stage 4)

EA-03 is the last amendment to Gate 1's criterion. If a later step produces a geometry response
shape that looks unexpected again, that is a scientific result to record, not grounds for another
adjustment to the gate. Holding this line is what keeps the gate from drifting to fit whatever data
shows up next.
